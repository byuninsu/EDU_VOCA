# Prepared blank answer cues

For every practice blank the app knows, offline, which wrong answers are
same-meaning words and which are other forms of the target word. It uses them
to show guidance instantly (`LocalClozeCheck`); no LLM is called while practicing.

- `same/*.json`: same-meaning words that fit each blank's exact sentence,
  authored by Claude (AI, Anthropic) on 2026-10-08 for 2,903 blanks
  (1,482 have at least one entry). App-authored data, CC BY-SA 4.0 like the
  other study data. Not expert-reviewed.
- Wrong forms are generated by `tools/build_cloze_cues.py` with English
  inflection rules (regular endings, irregular verb/plural/adjective tables)
  from each headword and its parts of speech.
- `sentences.json` records the sentence each list was written for. When an
  example sentence changes, the script reports it and omits that blank's
  same-meaning list until it is reviewed and `--freeze` is run.

A missing or imperfect entry only changes which guidance message appears;
it never changes what counts as correct.

Regenerate: `python tools/build_cloze_cues.py` → `lib/data/local/cloze_cues.dart`.
